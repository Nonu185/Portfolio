# Projects

## Orvyn — AI-Powered Search & Research Assistant
**Description:** Engineered an AI-powered search assistant using LangChain, Google Gemini, and Tavily for real-time web search and context-aware responses. Features a secure Node.js, Express.js, and MongoDB backend supporting JWT authentication and conversation thread management.
**Tech Stack:** LangChain, Google Gemini, Tavily, Node.js, Express.js, MongoDB, JWT
**Live Demo:** https://orvyn-ochre.vercel.app

## Interactive Developer Workspace & Portfolio
**Description:** Designed and built an interactive browser-based portfolio and personal workspace featuring functional window management, custom applications, and an integrated AI chatbot powered by RAG and Pinecone for real-time questions about profile, background, and deliverables.
**Tech Stack:** React.js, RAG, Pinecone, Google Gemini, SCSS
**Live Demo:** https://divyanshkumar.dev

## Flakes.pdf — Client-Side PDF & Image Utility
**Description:** Delivered a zero-server utility supporting image-to-PDF conversion, multi-file PDF merging, and file compression. Processes files entirely client-side using browser APIs to eliminate server infrastructure costs while ensuring total user privacy.
**Tech Stack:** React.js, Web APIs, Client-Side File Processing, Vercel
**Live Demo:** https://flakespdf.vercel.app

## NOC Simulator — Network-on-Chip Simulator
**Description:** Built an interactive simulator for Network-on-Chip (NoC) architectures in collaboration with a university professor. Visually demonstrates data routing and communication flow between nodes in real time through animated rendering.
**Tech Stack:** React.js, SVG/Canvas, Interactive Animation, Computer Architecture
**Live Demo:** https://noclang-simulator.vercel.app/
