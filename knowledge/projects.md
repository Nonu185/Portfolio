# Projects

## Web OS — Mac OS-inspired Browser OS / Portfolio
**Description:** Engineered a browser-based operating system simulation with 5+ functional apps, window management, and a Dock — resulting in a fully interactive developer portfolio with 0 external dependencies.
**Tech Stack:** React, JavaScript, CSS, HTML5

## NOC Simulator — Network-on-Chip Simulator
**Description:** Built an interactive visual simulator for Network-on-Chip architectures, reducing concept learning time for students by making data flow between nodes observable in real time through animated rendering.
**Tech Stack:** React, JavaScript, Frontend Animation

## Flakes.pdf — Client-side PDF & Image Utility
**Description:** Delivered a zero-server file tool supporting image-to-PDF conversion, multi-file PDF merging, and compression — processing files entirely client-side to eliminate server costs and ensure user privacy.
**Tech Stack:** React, JavaScript, PDF Processing APIs

## Orvyn — AI-Powered Search & Research Assistant
**Description:** Built an AI-powered search assistant using LangChain, Google Gemini, and Tavily for real-time web search and context-aware responses, with Node.js, Express.js, and MongoDB backend integration.
**Tech Stack:** Node.js, Express.js, MongoDB, Google Gemini, LangChain, Tavily
